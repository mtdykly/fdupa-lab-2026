# Lab3 过程间测例

本目录包含 18 个程序、24 个静态 abort，其中 8 个可达、16 个不可达。清单为 [interprocedural.json](../../interprocedural.json)；[all.json](../../all.json) 将这些程序与公共集合并，供 Lab3 统一评价。

| 编号 | 内容 | 观察点 |
| --- | --- | --- |
| 30–31 | 同一函数的两个调用点 | 30 在 k=0 时合并两次调用，k=1 可以区分；31 包含真实可达分支。 |
| 32–33 | `main → wrap → probe` | 32 的最后一层调用点相同，k=2 才能保留 main 中两个调用点的区别；33 包含真实可达分支。 |
| 34–36 | 实参之间的差关系与和关系 | 34、35 需要传递变量关系；36 的两个实参之和恒为 9，对应 abort 可达。 |
| 37–39 | 常量返回与多个 return | 37、38 利用返回摘要消除误报；39 的返回集合为 `{2, 4}`，凸抽象会把 3 包括进来。 |
| 40–41 | 多层调用中的 halt 与 abort | 终止整个程序的路径没有正常返回；41 仅最内层 abort 可达。 |
| 42–45 | 直接递归与相互递归 | 递归返回传播、固定点和不同递归基例。 |
| 46 | 没有返回基例的无限递归 | 函数始终继续调用自身，调用之后的 abort 不可达。 |
| 47 | 递归截断较早的调用点 | 两次入口的 value 分别为 0 和 2，最后两层调用点却相同，k=2 仍有误报。 |

各配置的参考告警集合位于 `tests/labs/expected/`。可以先比较区间与八边形，再比较同一域的 k=0、1、2；实验方法见 [Lab3](../../../../docs/lab3.md)。

清单的 `aborts` 给出逐条真值，可达项中的 `witness_input` 给出一组具体输入。空字符串表示该次执行不需要输入。
