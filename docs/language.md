# FDULang 语言规范

版本：0.1。FDULang 是程序分析课程使用的单文件命令式语言。它提供整数、局部变量、结构化控制流和递归函数，程序由解释器从 `main` 开始执行。本规范是前端和解释器的实现依据；当前实现的构建与运行方式见 [工具说明](tooling.md)。

完整文法见 [grammar.ebnf](grammar.ebnf)，可以直接用于编写递归下降解析器。文法规定语法形状，本文规定名称、表达式类别和数值检查等静态规则。示例见 [examples](../examples/README.md)。

## 一个完整程序

```text
fn increment(value) {
    return value + 1;
}

fn main() {
    let x = 0;
    input(x);
    if (x < 0) { halt; }
    if (x > 10) { halt; }

    let y = increment(x);
    while (y < 10) {
        y = y + 1;
    }
    if (y < 10) { abort; }
    halt;
}
```

程序中只有 `input` 读取控制台。`abort` 是需要分析的异常结束位置；`halt` 表示正常结束。语言不提供打印语句，解释器自身负责呈现执行结果与诊断。

## 文件与词法

源文件采用 UTF-8，扩展名约定为 `.fdulang`。允许文件开头的 UTF-8 BOM，BOM 不计入第一行的列号；其他位置的 BOM 不作为空白。源文件必须是有效 UTF-8，注释之外只允许下面定义的 ASCII token 和空白。

词法规则用以下正则表达式定义。`*` 表示零次或多次，`+` 表示一次或多次，`|` 表示选择，`[...]` 表示字符集合，`[^...]` 表示该集合之外的字符；反斜杠用于转义。

```text
identifier      = [A-Za-z_][A-Za-z0-9_]*
decimal         = [0-9]+
invalid_decimal = [0-9]+[A-Za-z_][A-Za-z0-9_]*
symbol          = <=|>=|==|!=|[(){};,=+\-<>]
whitespace      = [ \t\r\n\f\v]+
line_comment    = //[^\r\n]*
block_comment   = /\*([^*]|\*+[^*/])*\*+/
```

扫描时采用最长匹配。`whitespace`、`line_comment` 和 `block_comment` 被跳过；`invalid_decimal` 对应词法错误。完整匹配 `identifier` 后，按下面的关键字表确定 token 类别。其他无法匹配的字符是词法错误，未闭合的块注释也是词法错误。

```text
fn  let  input  if  else  while  return  halt  abort
```

标识符区分大小写。`main` 是具有入口要求的普通函数名。空白包括空格、制表符、换行、回车、换页符和垂直制表符；LF、CRLF 或单独 CR 均视作一次换行。

行注释到行末或文件末尾结束。块注释不嵌套，第一个 `*/` 结束注释。注释位于 token 之间，`a/*...*/b` 产生两个标识符 token。

整数常量仅有十进制数字，允许前导零，`010` 的值为十进制 10。正负号是独立 token。`invalid_decimal` 包含数字串后紧接字母或下划线的形式，如 `12abc`、`1_000`、`0x10`；数值范围按下一节的静态规则检查。

双字符运算符 `<= >= == !=` 由最长匹配优先识别。`++`、`--` 分别识别为两个符号，例如 `x--1` 按 `x - -1` 解析，`--x` 按两次一元负号解析。

诊断位置包含文件、行和列，均从 1 开始。列按该行的 UTF-8 字节数计数，制表符算一个字节；它不是显示终端的字符宽度。源码区间保留原文件的字节偏移，结束位置不包含在区间内。

## 整数与表达式

唯一可存储的值是有符号 32 位整数，范围为 `[-2147483648, 2147483647]`。普通十进制常量的数值必须在 `[0,2147483647]` 内。

为允许最小负数，有一条静态例外：数值为 `2147483648` 的常量只能作为一元负号的直接操作数，忽略包裹这个常量的括号。该组合表示整数 `-2147483648`。它不是运行时把一个非法正数取负。

| 写法 | 结果 |
| --- | --- |
| `-2147483648`、`-(2147483648)` | 合法，值为最小整数 |
| `2147483648`、`0 - 2147483648`、`-(+2147483648)` | 静态数值范围错误 |
| `2147483648 - 1` | 静态错误，不能先折叠成合法值 |
| `--2147483648` | 静态合法；运行时外层取负溢出 |
| `2147483647 + 1 - 1` | 静态合法；运行时第一步加法溢出 |

超过 `2147483648` 的常量总是静态错误，不能依赖宿主整数转换的回绕。前导零不改变以上数值规则。

表达式允许变量、常量、函数调用、括号、一元正负号、加减和比较。结合顺序如下：

| 从高到低 | 规则 |
| --- | --- |
| 括号和调用 | 括号改变分组；调用实参按从左到右求值 |
| 一元 `+ -` | 右结合，`-+x` 等于 `-(+x)` |
| 二元 `+ -` | 同级左结合，`a-b-c` 等于 `(a-b)-c` |
| `< <= > >= == !=` | 不可连写；`a < b < c` 是语法错误 |

表达式有两个仅用于静态检查的类别：**整数**和**条件**。变量、常量、调用返回整数；加减及一元运算的操作数必须是整数，结果也是整数。比较两侧必须是整数，结果是条件。括号保持内部类别。

只有 `if` 和 `while` 的条件位置接受条件类别。声明、赋值、实参和 return 只接受整数，不允许把条件保存成整数或用整数充当真假值。例如 `if ((x < y))` 合法，`if (x)`、`let b = x < y;`、`(x < y) + 1` 都是静态错误。这一设计支持自然的括号写法，而无需可存储的布尔类型。

所有操作严格从左到右求值。每一步加减和一元负号都检查结果是否越界，越界立即产生 `runtime_error`；没有回绕或饱和算术。比较直接比较两个合法整数，不通过可能溢出的 `left-right` 实现。中间步骤不得因代数化简被省略。

`&&`、`||` 和逻辑非不在本版语法内。组合条件使用嵌套分支；反向条件可使用对应的比较符。

## 函数和名称

源文件只包含一个或多个顶层函数定义。函数名全文件唯一，不支持重载、函数声明原型或嵌套函数。必须恰好定义一个零参数 `main`；缺少 main 或 main 有参数都是静态错误。

所有函数签名在检查函数体前收集，因此允许前向调用、直接递归和相互递归。调用的函数必须存在，实参数量必须与形参数量相同，参数均按值传递。函数体内给参数赋值不会改变调用者变量。

函数名称与变量名称分属两个空间：`f(...)` 总是按全局函数名解析，单独的 `f` 总是按当前词法作用域中的变量解析。变量不能保存函数；不存在间接调用。

形参名在同一函数中唯一。局部变量必须用 `let name = expression;` 声明并初始化。首版要求同一函数所有形参与局部声明名字互不相同，包括两个不同分支中的声明；不同函数可以使用相同名字。

参数在整个函数体可见，局部变量从其初始化表达式求值完成后，到所在块结束之前可见。变量不在自己的初始化表达式中可见；离开块后不可访问。不存在隐式声明、隐式初始化或全局变量。整个文件都先做静态检查，包括不会执行到的代码。

```text
fn main() {
    let x = 1;
    {
        let y = x + 1;
        x = y;              // 可以修改外层变量
    }
    // y = 3;               // 若取消注释，是名称不可见错误
    halt;
}
```

## 语句与控制流

| 语句 | 行为 |
| --- | --- |
| `let x = e;` | 计算 e，成功后创建并初始化 x |
| `x = e;` | 在旧状态计算 e，成功后覆盖已声明的 x |
| `f(a, b);` | 调用函数并丢弃正常返回值 |
| `input(x);` | 读一个整数并写入已声明的 x |
| `if (c) { ... } else { ... }` | 计算条件一次，只执行选中的分支 |
| `while (c) { ... }` | 每轮先重新计算条件，为真才执行循环体 |
| `return e;` | 先计算 e，再结束当前调用并返回整数 |
| `halt;` | 立即正常结束整个程序 |
| `abort;` | 立即异常结束整个程序，报告该源码位置 |
| `{ ... }` | 顺序执行一个具有局部作用域的块 |
| `;` | 空语句，不改变状态 |

分支与循环体必须有花括号，`else` 可以省略。允许 `else if (...) { ... }`，它等价于 else 块中嵌套一个 if。无 `break`、`continue`、`for` 或 `goto`。

循环体每次进入都会重新执行其中的局部声明；这些局部变量不保留上一轮的值。条件中的函数调用也会每轮重新执行。局部变量数量在源码中有限，递归调用的动态栈帧则相互独立。

函数执行到末尾，相当于 `return 0;`，不允许省略表达式的 `return;`。最外层入口 main 返回时程序正常结束，返回整数被忽略。允许显式调用 main；它作为普通函数被调用时，return 只回到该调用者，只有入口调用的返回结束程序。

若任何被调函数执行 halt、abort、发生运行时错误或不返回，调用者就不会继续执行该调用之后的表达式或语句。例如 `left() + right()` 中 left 执行 halt 时，right 不会被调用。

## 输入和执行结果

`input(x);` 跳过 ASCII 空白并读取一个空白分隔 token。合法输入必须完整匹配 `[+-]?[0-9]+`，且数值在整数范围内；允许前导零、`+0` 和 `-0`。`12x` 不能被读成 12，`1,2` 也不是两个整数。

非法 token、越界输入或需要读取时已到输入末尾都会产生 `runtime_error`，停止整个程序，不回退或重试。读取失败时 x 不更新。尚未读取的输入不影响程序执行；输入提示不是语言语义的一部分。

解释执行的结果类别如下，具体命令行退出码留给工具接口规范：

| 结果 | 含义 |
| --- | --- |
| `normal` | halt，或入口 main 正常返回 |
| `abort` | 实际执行到某个显式 abort，附静态 ID 和源码位置 |
| `runtime_error` | 算术溢出、输入无效、输入结束或输入读取失败 |
| `resource_limit` | 执行器步数、栈深度等配置限制触发 |
| 前端错误 | 词法、语法、名称、表达式类别或常量范围错误；不开始执行 |

非终止程序合法。资源限制属于工具配置，不是语言中隐藏的 halt 或 abort。工具内部故障也不能伪装成源程序 abort。

## 静态位置和分析对象

每个源码 `abort;` 分配一个文件内唯一的 `A1`、`A2`……编号，按 abort 关键字的原文件字节偏移升序排列。不可达语句和未被调用函数中的 abort 也进入完整清单。注释不产生语句，同一位置因循环或递归多次执行仍只有一个 ID。

每个显式函数调用表达式同样按被调函数名 token 的字节偏移编号为 `C1`、`C2`……。例如 `outer(inner())` 中 outer 的调用点 ID 在 inner 前，但实际先执行 inner。入口的隐式 main 调用不占用显式调用点 ID。

编号在同一源码上不随分析域、上下文深度或遍历次序改变；编辑源码可能改变编号，测试记录须关联源码哈希。表达式求值顺序由 CFG 表示，不能由 ID 大小推断。

程序分析的阳性目标是“存在从入口 main 开始、使用合法范围内整数输入的执行，能够到达这个显式 abort”。分析结果允许保守误报。前端错误、运行时错误和资源限制不自动增加 abort；合法但未终止的执行也不会因此到达后面的语句。

## 本版不包含的特性

不提供乘除、布尔变量、数组、字符串、浮点、指针、引用参数、堆、全局变量、异常捕获、动态函数值、多文件或并发。此边界限制实现工作量；分析域无法精确表示的合法加减表达式仍必须接受，并由分析器安全近似。
